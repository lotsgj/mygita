# Purpose and principles

**Status:** Partial
**Last updated:** 29 October 2026

## Purpose

MyGita is a personal, verse-centred platform and app for reading, listening, chanting, contemplating and gradually building a meaningful relationship with scriptural teachings. It begins with the Bhagavad Gita and is designed to support Suktas, Advaita compositions and later verse collections without fragmenting the shared experience or engine.

The source repository has adopted the MyGita name. The currently deployed Bhagavad Gita application still uses the Gitaverse name and origin; its app-brand, domain and local-data migration remain a deliberate later transition.

## Product principles

- **The verse is central.** Navigation, language, audio, and future media support the shloka rather than compete with it.
- **Calm before novelty.** The interface should feel serene, text-friendly, and usable for sustained reading.
- **One person, one local journey per product.** Profiles separate preferences and progress on a shared device without requiring authentication; independently deployed products keep their own origin and storage boundary.
- **Stable identity.** Every canonical record uses SID, such as `6.B`, `6.7`, or `6.E`.
- **Language is a perspective on shared content.** Sanskrit, English, and Kannada records align by SID.
- **Products contain collections; experiences present them.** Canonical text and reusable media remain independent of both packaging and presentation.
- **Progressive capability.** The same application should work online, as an installed PWA, and—with an explicit folder choice—for local editing.
- **Privacy by design.** Profile details remain local. Analytics uses grouped, non-PII context.
