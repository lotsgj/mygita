# Suktaverse product

This product currently defines the first Suktaverse experience: **Sukta Chant**,
powered by the shared Player-4 renderer and the 18 learning units in the
Ganesha Atharvashirsha collection.

The data contract and local experience are ready for verification. Product
branding assets, PWA icons and the deployment workflow remain a later tranche;
until those are supplied, `build:distribution sukta` intentionally remains
incomplete. Shared runtime code remains in `engine/`.
